# Distracted Driver Analysis

This project is a three-part data science analysis focused on distracted driving behavior, traffic safety, and driver-related risk factors. The project uses Python-based data analysis and visualization techniques to explore patterns associated with distracted driving and roadway safety.

## Project Structure

### Part 1
Data loading, preprocessing, and exploratory analysis of distracted driving datasets.

### Part 2
Visualization of driver behavior trends, accident-related factors, and traffic safety metrics.

### Part 3
Advanced analysis, conclusions, and interpretation of distracted driving risk patterns.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## Key Concepts

- Exploratory data analysis
- Traffic safety analysis
- Data visualization
- Risk factor analysis
- Behavioral trend analysis
- Data preprocessing
